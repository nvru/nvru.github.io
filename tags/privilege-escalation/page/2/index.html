    p4l4nc4 (Palanca) - Walkthrough

    July 18, 2026
    Ctf, Walkthrough, Linux, Apache, Lfi, Ssh, Privilege-Escalation

    Overview#

    • Attacker IP: 10.10.10.2
    • Target Machine IP: 10.10.10.27

    The objective was to enumerate the target, identify exposed services, gain initial access through a Local File Inclusion (LFI) vulnerability, and escalate privileges by abusing insecure permissions on /etc/passwd.

    Port Scanning#

    RustScan#

    rustscan -a 10.10.10.27 -- -sC -sV -A -oA nmap/rust

    Results#

    PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 9.2p1 Debian 2+deb12u3
80/tcp open  http    Apache httpd 2.4.62 ((Debian))

    Only SSH and an Apache web server were exposed, making the web service the obvious starting point.

    Immortal - Walkthrough

    July 10, 2026
    Ctf, Walkthrough, Linux, Ftp, File-Upload, Reverse-Shell, Sudo, Systemd, Privilege-Escalation

    Overview#

    • Attacker IP: 10.10.10.2
    • Target Machine IP: 10.10.10.20

    The objective was to enumerate the target, identify exposed services, gain initial access through an unrestricted file upload vulnerability, and escalate privileges by abusing writable Python code and a misconfigured systemctl sudo rule.

    Discovering the Target#

    First, I identified the target IP address on the local network.

    sudo arp-scan --interface vboxnet0 --localnet

    Output:

    Interface: vboxnet0, type: EN10MB, MAC: 0a:00:27:00:00:00, IPv4: 10.10.10.2
10.10.10.20     08:00:27:13:bb:b5       PCS Systemtechnik GmbH

    Port Scanning#

    RustScan#

    rustscan -a 10.10.10.20 -- -sC -sV -A -oA nmap/rust

    Results#

    21/tcp open  ftp     vsftpd 3.0.3
22/tcp open  ssh     OpenSSH 8.4p1
80/tcp open  http    Apache httpd 2.4.56

    The machine exposed only three services: FTP, SSH, and HTTP.
